# Руководство пользователя

## Вход в панель

1. Откройте публичный HTTPS-адрес панели.
2. Введите `ROUTER_SUPPORT_ENGINEER_TOKEN`.
3. После проверки сервер создаст подписанную защищённую HttpOnly-cookie на 12 часов.

При неверном токене сервер отвечает `403` и не отдаёт основной HTML, JavaScript и CSS
панели. Сам инженерный токен в браузере не сохраняется. После входа в шапке панели
показывается отдельный токен подключения OpenWrt с кнопкой копирования.

Получить токен может администратор VPS:

```sh
grep '^ROUTER_SUPPORT_ENGINEER_TOKEN=' /etc/router-support/backend.env
```

## Список устройств

Карточка показывает:

- hostname и модель;
- версию OpenWrt и UUID;
- LAN/base MAC-адрес;
- назначенный reverse SSH-порт;
- время последнего heartbeat;
- статус online/offline.

Статус online означает, что heartbeat получен в пределах настроенного таймаута.
Поле поиска фильтрует hostname, UUID и модель.

## Переименование

Нажмите значок карандаша рядом с hostname. Допустимы латинские буквы, цифры и дефис,
длина — до 63 символов. Изменение применяется на самом OpenWrt через UCI и затем
отображается в базе.

## Начало поддержки

Нажмите «Начать поддержку». Сервер:

1. проверит online-состояние и права;
2. создаст временную сессию;
3. откроет локальные SSH-форварды на VPS;
4. выдаст защищённые ссылки сервисов.

Доступны:

- **LuCI** — интерфейс OpenWrt;
- **V2RayA** — если сервис включён на роутере;
- **SSH** — интерактивный root-терминал в браузере;
- **Web App** — показывается только после включения сервиса на порту `2018`.

Сервисные ссылки получают HttpOnly cookie через одноразовый секрет во fragment URL.
Fragment не передаётся серверу и не попадает в access log.

## Веб-SSH

Кнопка SSH существует только в активной support-сессии. Терминал поддерживает обычный
ввод, Enter, Tab, Backspace, стрелки, вставку и `Ctrl+C`. Ticket одноразовый и действует
30 секунд. Терминал имеет root-доступ — выполняйте команды осознанно.

## Завершение поддержки

Нажмите «Завершить поддержку». Сервер уничтожит SSH-процесс, терминалы и локальные
форварды. Старые ссылки сразу начнут возвращать `403`. Без ручного завершения сессия
закроется по таймауту, по умолчанию через один час.

## Удаление устройства с OpenWrt

Удаление выполняет администратор. Обычный режим сохраняет идентичность для повторной
установки, а `--purge` удаляет её полностью. Команды и последствия описаны в
[руководстве эксплуатации](OPERATIONS.md#удаление-агента-с-роутера).
